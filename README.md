# Ciptadana redesign review prototype

Static review prototype exported from the saved MAGIKA MagicPath design. Company-approved content and integrations remain pending; enquiry confirmation is local and sends nothing to the company.

Build with `npm install` then `npm run build`. Publish the `docs/` folder with GitHub Pages. The website uses hash routes so nested pages work on static hosting. Design system and English rationale: `design-system/`.

Frozen source revisions: website458539117089787904; tablet458538250823421952; mobile458538305324220416; DS458569379198701568. Website is the responsive desktop source; all viewport boards share its route/content model. DS links are rewritten to this exported website. Image sources remain authentic normalized MagicPath asset URLs; Inter font is fetched from Google Fonts.

This package is built, but has not been published or browser-tested on GitHub Pages. No authentication, financial transactions or live enquiry submission is implemented.
